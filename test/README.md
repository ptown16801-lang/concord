# Tests and fixtures

These are Node built-in test-runner checks for the code in this checkout. Run `npm test` from the repository root. Use `node --test test/<file>.test.js` for an identified focused test file.

Fixtures model bounded behavior and failure conditions. Passing them does not establish full-system integration, independent acceptance, or deployment. For a result or regression report, include the tested commit, Node version, command, and outcome. See [development status](../docs/PROJECT_STATUS.md) before comparing test results from different branches.
