# Runtime source

At the documented default baseline, `server.js` serves the browser demonstration and HTTP ingestion endpoint. `finger/` contains identity association, session ingestion, SQLite and object-store persistence, and replay/heat-map processing.

See the [development guide](../docs/DEVELOPMENT.md) for startup and the [component reference](../docs/reference/component-runtime.md) for configuration and storage boundaries. These components are part of Concord; they do not implement the full institutional environment. The [status page](../docs/PROJECT_STATUS.md) links to separate governance and research candidates.
