## Required correction set

PR #21 does not conform to JON-96 until all five corrections below are made:

1. Scope the §2 information boundary to outputs of the coin module, not all information an agent can receive.
2. State the frozen ordinary-run prohibition on manual researcher steering/correction.
3. Remove the legitimate-only precondition from copy semantics while preserving the legitimate-copy and fraud-instance distinction.
4. Stop generating a destruction claim from an actual destruction; preserve optional claims separately from ground truth.
5. Correct §7’s unresolved list so it distinguishes genuinely undecided model content from downstream representation, implementation, instrumentation, and experiment-design choices.

No correction is required for the frozen issuance, transfer, valuation, privacy, signature, verification, intent, or hidden-layer non-leakage boundaries. These findings require amendments to JON-97 only; they do not authorize or duplicate the threat model or hidden instrumentation contract owned by JON-99 and JON-100.
