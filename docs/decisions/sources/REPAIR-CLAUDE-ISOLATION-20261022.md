# Isolated advisory execution

This sanitized source summary was prepared October 22, 2026 from retained project
records. It is a derivative, not an unchanged original or a new policy decision.

CON-094 at local commit ed8c060c25c3c4a7eb0630395fc615ee7927c8db
records the September 30 requirement that separately authorized Claude advice use
the established isolated worker route instead of the main user's provider process.
The maintained project instruction independently retains that requirement: the
worker receives a bounded packet of authorized evidence and applicable instructions;
it cannot inspect project paths or edit files. Local Codex applies and tests any
proposed changes. Failure does not authorize main-user or paid fallback, access
expansion or automatic invocation.

This changes routing, not roles, scope, disclosure, spending, holds or review
independence. It grants no standing implementation or verification role to the
advisor. Exact host accounts, commands, paths and private operating receipts remain
outside public documentation. Historical inspection is not a current availability,
login, entitlement, isolation or model-execution verification.
