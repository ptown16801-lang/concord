## Schema note

This is an explicit versioned implementation profile, not permission for downstream modules to invent a second identity model. Any normalization should preserve GOV ID and evidence provenance.

The current v1 profile remains valid for the shipped Workbench. A separate follow-up should normalize representation toward the logical contract rather than silently changing the deployed schema under existing consumers.
